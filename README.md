# 🏎️ Neon Drift - Arcade Racing Simulation

NEON DRIFT is a high-octane, browser-based top-view car racing game built with a premium "Neon Industrial" aesthetic. This project was developed as a Case Study for **ITM Skills University** (B.Tech CSE 2025-29).

## 🌟 Key Features

- **The Garage (Car Selection)**: Choose from over 10+ legendary vehicles (Porsche, BMW, Audi, etc.) before hitting the tracks. Each car features unique visuals.
- **Dynamic Difficulty**: Smooth acceleration curve that increases the game speed every 10 seconds to test your reflexes.
- **Global Leaderboard**: Save your high scores locally and compete across Bronze, Silver, and Gold tiers.
- **Premium Navigation**: A floating glassmorphism navbar and a redesigned "Wondermakers" inspired footer.
- **Interactive Scenery**: Procedurally generated environment (Trees, decorations) for an infinite racing experience.

## 🛠️ Technical Implementation

### HTML5
- Semantic structure for views (Home, Play, Leaderboard, Forum).
- High-performance Canvas element for the main game engine.

### CSS3 (Modern Styling)
- **Glassmorphism**: Transparent, blurred UI panels for a futuristic look.
- **Animations**: Custom keyframes for hazard-stripe borders, glitch text effects, and smooth section transitions.
- **Responsiveness**: Fully responsive layout that adapts to different screen sizes.

### Vanilla JavaScript
- **Game Engine**: Custom loop for obstacle spawning, collision detection, and score calculation.
- **State Management**: Handles view switching and car selection logic.
- **Persistence**: Uses `localStorage API` to keep track of your rank on the leaderboard.

## 🎮 How to Play

1. **Launch**: Open `index.html` in any modern browser.
2. **Select Car**: Navigate to the "READY TO RACE" section and use the arrows to pick your ride.
3. **Controls**:
   - `Arrow Keys` or `WASD`: Movement (Left/Right)
   - `Spacebar`: Nitro / Speed Boost
4. **Objective**: Avoid obstacle cars, travel the maximum distance, and survive the increasing speed to climb the rankings.

## 📂 Project Structure

- `index.html`: The main entry point and UI structure.
- `style.css`: The entire design system and animations.
- `script.js`: Game logic, interactions, and car selection.
- `assets/`: Images and sounds used in the game.
